# gta6-text-en

English text dump extracted from **GTA 6 — Xbox Build 1.0.2.1 (Nov 2026)**.

Source / dump credit: **CyberLeek**

## Contents

| File | Description | Approx. rows |
|------|-------------|--------------:|
| `GTA6_text_EN.xlsx` | Spreadsheet with sheets `Core`, `Story`, `Minigame` | — |
| `all_rows.tsv` | Consolidated EN rows (id, pack, table, hash, category, group, ukey, text) | ~579k |
| `raw_american.tsv` | Raw American/Core text table dump | ~324k |
| `raw_american_story.tsv` | Raw Story text table dump | ~254k |
| `raw_american_minigame.tsv` | Raw Minigame text table dump | ~1.8k |

## Notes

- Language: American English (`american`)
- Build: Xbox **1.0.2.1**, November 2026
- Raw TSV columns: `table`, `table_offset`, `idx`, `hash`, `text`
- Consolidated TSV columns: `id`, `pack`, `table`, `idx`, `hash`, `category`, `group`, `keep`, `ukey`, `en`
